# RHESSysEastCoast

This github repository holds a developing branch of RHESSys (https://github.com/laurencelin/RHESSysEastCoast) 

Modifications: 
- Ditches are added, specified in set up with raster file and associated with action code 11 (replaces sewer action code)
- If the depth to saturated zone of the patch that contains a ditch is lower (shallower) than the depth of the ditch of that patch (assumed to be 1m for now), than that water should get added to surface runoff.
